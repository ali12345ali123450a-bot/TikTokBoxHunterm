# TikTok Box Hunter v2

تطبيق أندرويد تجريبي بواجهة سوداء وذهبية يجمع مؤقت الصندوق مع قائمة روابط البث وفلاتر العملات في مشروع واحد.

## المزايا الحالية
- مؤقت قابل للتعديل مع صوت واهتزاز عند انتهائه والتطبيق مفتوح.
- إضافة اسم صاحب البث وعدد العملات ورابط البث.
- فتح رابط البث في TikTok أو المتصفح.
- فلاتر: الكل، أقل من 200، 200 بالضبط، أكثر من 200.
- ترتيب النتائج من أعلى عدد عملات إلى أقل.
- سير عمل GitHub Actions لبناء APK ورفعه كـ Artifact.

## حدود مهمة
القائمة يدوية في هذه النسخة: لا يوجد اتصال رسمي يكتشف كل بثوث TikTok أو يقرأ قيمة الصندوق تلقائياً. أدخل رابط البث وقيمة الصندوق بنفسك. لا توجد ضغطات آلية ولا جمع تلقائي للعملات. لا يمكن ضمان بقاء المؤقت يعمل إذا أغلق النظام التطبيق أو أوقفه.

## بناء APK من GitHub
بعد رفع ملفات المشروع إلى المستودع:
1. افتح تبويب Actions.
2. اختر Build Android APK.
3. اضغط Run workflow إذا لم يبدأ تلقائياً.
4. بعد نجاح البناء، افتح التشغيل الناجح وانزل إلى Artifacts.
5. نزّل TikTokBoxHunter-debug-apk ثم فك الضغط وثبّت APK.

يستخدم GitHub Actions Gradle 8.9 وJDK 17 لبناء نسخة Debug.

## تنبيه
التطبيق لا يكتشف بثوث TikTok تلقائياً ولا يضغط على الصندوق ولا يجمع العملات. يجب إدخال رابط البث وقيمة العملات يدوياً، والضغط النهائي منك.
